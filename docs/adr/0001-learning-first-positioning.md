# 学习型项目定位与第一阶段边界

YokeOS 定位为学习型项目：通过全程 AI 编程复刻 OryxOS，学习 Agent 开发与企业级 AI 编程方法论，长期演化为企业级开源 Agent OS。**第一阶段的使命是学习，高于交付**——未来读者看到本库与 oryxos 高度同构却不完全相同，原因即在此。阶段边界对齐 OryxOS 自身的 Phase 1（单机内核，课程第 16~31 节），第一阶段 DoD：

1. 立项文档链五件套 + 产品定位完成
2. 第 16→31 节逐节跟拍，每节有验收报告（含方法论对照节）
3. 等价第 31 节：真实运行 + GitHub release v0.1.0
4. 等价第 32 节：阶段总结 + SDD 方法论反检记录
5. 测试密度 ≥88%

参照库 `vendors/oryxos` submodule 钉 `origin/main`（课后演进与 release 参照）；教学文章不在 main 上，经本地保留的 `class-30` 分支访问，因版权不拷入本仓。

## Considered Options
